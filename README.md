## ⚡ Harry-Potter-AI-Bot Frontend (React)

This is the **frontend React application** for the magical 🧙‍♂️ `Harry-Potter-AI-Bot`. Designed to deliver an immersive and enchanting user experience, this UI allows users to chat with an AI trained on the Harry Potter universe. The bot uses embedded book knowledge via Pinecone and is powered by OpenAI — all wrapped in a beautiful wizarding-world-inspired interface.

---

### ✨ Features

- 💬 Chat with the AI like you're in the Gryffindor common room
- 📚 Styled in Harry Potter theme with Hogwarts house colors
- 🌐 Toggle between **book-only answers** and **fan-based insights**
- 🎭 AI replies with in-character personality (lore-based responses)
- 🔮 Smooth UI for real-time interaction and magic animations
- 📱 Fully responsive (desktop + mobile)

---

### 🧙‍♂️ Tech Stack

- **Frontend**: React (Vite or CRA)
- **Styling**: TailwindCSS + custom Harry Potter themes
- **State Management**: React Context API or Redux (optional)
- **API Integration**: OpenAI GPT + Pinecone backend endpoints
- **Animations**: Framer Motion / CSS wizard sparkles

### 🛠️ Setup Instructions

#### 1. Clone the Repository

    git clone https://github.com/your-username/harry-potter-ai-bot-frontend.git
    cd harry-potter-ai-bot-frontend

#### 2. Install Dependencies
       
    npm install

#### 3. Set API Endpoint
   
   Create a .env file and add your backend API URL:
   
    npm run dev
    
- Then visit: http://localhost:5173
